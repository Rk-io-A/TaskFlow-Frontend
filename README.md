# TaskFlow Frontend

React 19 + Vite + TypeScript + Tailwind + React Query + Zustand

## Run

```bash
npm install
npm run dev
```

Set `VITE_API_URL=http://localhost:5000/api` in `.env`

## Deploy

- **Azure Static Web Apps** or **Vercel**
- Env: `VITE_API_URL=https://your-api.azurewebsites.net/api`
